# Hero of Knowledge School Website

Next.js 15 website for Hero of Knowledge School (Creche, Nursery & Primary).

## Branding

The official school crest supplied by the school is stored at:

`public/assets/hero-of-knowledge-school-logo.jpg`

The same original image is used in the header, hero area, Founders Corner panel, footer, and site icon metadata. Do not redraw or recolour the crest.

## Local development

Requirements: Node.js 22.x and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

Import this repository in Vercel. Framework: Next.js. Root directory: `./`. Build command: `next build`. Install command: `npm install`. Node.js: 22.x.

## Content requiring school approval

The school's official contact details, founder profile/message, event notices, real gallery photographs, term dates, and admissions details are intentionally not invented. Replace the relevant on-page notes once the school supplies approved information.
